# Visual direction

AppSea should feel focused, technical, calm, and current. Use near-black backgrounds, deep navy surfaces, thin cool-gray borders, and controlled violet, indigo, blue, and cyan accents.

## Shared rules

- Give every route one dominant content surface.
- Keep the global header narrow and quiet.
- Prefer one list or a small group of closely related cards.
- Keep card radii, borders, and spacing consistent.
- Use glow only for active states, top ranks, important scores, and primary actions.
- Remove panels before shrinking type below readable sizes.
- Use green, amber, and rose only for meaningful status.

## Route boundaries

- Leaderboard: heading and ranked list only.
- Opportunity: one idea, score, momentum, confidence, rationale, complaint themes, and first-version direction.
- Complaints: compact source filters and evidence records.
- Competitors: one comparison table on desktop and stacked competitor cards on mobile.
- Plan: build brief, core scope, stack, implementation steps, and one action area.

## Typography

Use a modern sans-serif family, strong number rendering, compact bold headings, and muted cool-gray supporting text. Do not preserve desktop density by shrinking mobile text.
