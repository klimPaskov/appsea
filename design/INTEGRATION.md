# Repository integration

Copy `design/references` into the AppSea repository and link each route plan to both its desktop and mobile image.

Recommended documentation destinations:

```text
design/references/desktop/
design/references/mobile/
design/references/reference-map.json
docs/design/appsea-visual-direction.md
docs/design/appsea-mobile-behavior.md
```

Do not ship the reference images in the production application bundle. Use deterministic fixtures for screenshot comparison. Record intentional deviations caused by accessibility, corrected copy, real data, browser rendering, or later product requirements.
