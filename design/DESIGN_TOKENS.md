# Suggested design tokens

| Token         | Value     | Use                       |
| ------------- | --------- | ------------------------- |
| `--bg`        | `#050814` | Page background           |
| `--surface-1` | `#0A1020` | Main surfaces             |
| `--surface-2` | `#0E1629` | Raised surfaces           |
| `--border`    | `#2A3550` | Cool low-contrast borders |
| `--text`      | `#F5F7FF` | Primary text              |
| `--muted`     | `#9AA6C1` | Supporting text           |
| `--violet`    | `#865DFF` | Primary accent            |
| `--blue`      | `#4EA1FF` | Accent endpoint           |
| `--cyan`      | `#37D5E6` | Supporting accent         |
| `--positive`  | `#63D77D` | Positive movement         |
| `--warning`   | `#F3A642` | Medium severity           |
| `--danger`    | `#FF5B7D` | High severity             |

Use a 4-pixel spacing base. Common values are 8, 12, 16, 20, 24, 32, 40, 56, and 72 pixels. Use 16 to 20 pixel row radii and 20 to 24 pixel major-panel radii.
