# ADR 0005: Use simple single-purpose screens

- Status: accepted
- Date: 2026-07-10

## Decision

The leaderboard page shows only the ranked list. Complaint evidence, competitors, and coding plans use separate routes.

## Reason

The first references were dense and behaved like an admin dashboard. The product needs fast scanning and clear boundaries between public ranking and deep research.

## Consequence

New dashboard cards or side panels require a product decision, not casual UI expansion.
