# AppSea UI reference loop

Read `design/briefs/simple-interface.md` and the local app instructions.

## Procedure

1. Define the one job of the screen.
2. Remove information that belongs on another route.
3. Update the deterministic reference source and render the reference image.
4. Implement semantic HTML and responsive CSS.
5. Capture the actual page at desktop and mobile sizes.
6. Compare hierarchy, field count, spacing, type scale, borders, alignment, focus states, and overflow.
7. Test keyboard navigation and reduced motion.
8. Iterate until the implemented screen serves the same focused purpose.

## AppSea-specific constraints

The leaderboard page shows only navigation, the heading, rank, opportunity, complaint count, score, and a small fixture disclosure. Do not add summary cards, charts, preview panels, or research status.

## Completion

Reference and implementation are separate artifacts, the actual page has browser evidence, and accessibility checks cover the changed interaction.
