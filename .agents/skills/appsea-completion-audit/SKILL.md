# AppSea completion audit

This is a read-first audit. Compare the user request, goal prompt, accepted plans, specs, code, tests, docs, memory, skills, and generated artifacts.

## Audit

- requested product surfaces
- contracts and migrations
- source policy and provenance
- collection, normalization, deduplication, clustering, competitor research, contrary evidence, and scoring
- report and coding package generation
- website and API
- worker durability and recovery
- security and privacy
- runtime autonomy gates
- docs, memory, and skill maintenance
- task-specific validation
- simplifications and missing work

Do not treat a generated report as proof that its inputs are correct. Do not mark completion when a visible UI masks fixture-only or missing backend behavior.

## Output

Write a completion report with status by surface, evidence, failed or missing checks, unresolved blockers, and exact next actions. State every simplification that changed scope.

## Completion

The main agent can make an honest final claim supported by code, tests, artifacts, and aligned documentation.
